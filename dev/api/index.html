ArrowMacros.@↑ — Macro
@↑ s = a, b ← f(c)

Write values to properties of s. @↑ s = a, b sets s.a = a and s.b = b. The right of ← is ordinary code in the caller's scope, not rewritten as in @↓: @↑ s = a ← 2b sets s.a = 2b, with b the local variable.

ArrowMacros.@↓ — Macro
@↓ a, b ← f(c) = s

Unpack properties of s into variables. @↓ a, b = s binds a = s.a and b = s.b. The arrow renames or transforms: @↓ x ← b = s binds x = s.b, and the right of ← may be an expression in which bare symbols read as properties of s: @↓ x ← 2a + b[1] = s binds x = 2s.a + s.b[1].

In the expression form, function names, macro names, qualified names (Base.abs) and keyword names are left alone, and so are literals, the constants nothing, missing, π, ℯ, im, Inf, NaN, and begin/end inside indexing. Other bare symbols are properties of s. A bare name on its own to the right of ← is always a property: @↓ x ← π = s reads s.π. Chained access a.c is not rewritten: bind the property first. Quoted expressions (:(a + 1)) are left alone. Anonymous functions and comprehensions that introduce local names are unsupported. A name that is not a property of s throws the usual error.
